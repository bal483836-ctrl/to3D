# 50 视角多模态数据集生成（Color / Depth / Normal / Mask）

对生成的文物模型，按参考 `datasets/reference_meta_data.json` 里 **50 组固定相机参数**
渲染四种模态数据，并为每件文物写出结构一致的 `meta_data.json`。

**严格约束**：所有文物使用参考文件中**相同**的 50 组 `camtoworld`、`intrinsics`、
视角顺序、`800×800` 分辨率；脚本**不随机生成、不修改**相机参数。

---

## 1. 用法

### 方式 A：产品里「一键生成」（推荐）
1. 正常图+文生成模型完成后，右侧出现按钮
   **「✦ 一键生成 50 视角数据集」**。
2. 点击 → 后台调用 Blender 渲染 50×4 → 完成后出现 **下载数据集 (zip)**。
3. 需服务器装 Blender，并设 `TO3D_BLENDER_BIN`（见 `.env.example`）。

### 方式 B：命令行直接跑 Blender
```bash
blender -b --python tools/blender_render_views.py -- \
  --model /path/artifact.glb \
  --meta  datasets/reference_meta_data.json \
  --out   /path/out_dir \
  --engine CYCLES --samples 64
```

## 2. 输出（每件文物一份目录）
```
out_dir/
  0_colors.png 0_depth.exr 0_normal.png 0_mask.png
  1_colors.png 1_depth.exr 1_normal.png 1_mask.png
  ... （共 50 组）
  meta_data.json        # 与参考同结构：camera_model/height/width/worldtogt/scene_box/frames
```
- **Color**：彩色渲染（RGBA，alpha 即掩码来源）。
- **Depth**：深度，默认 `OpenEXR` 保真（`--normalize-depth` 另出归一化 PNG）。
- **Normal**：法线，`(N*0.5+0.5)` 映射到 `[0,1]` 存 PNG。
- **Mask**：文物掩码（film 透明背景 → alpha 通道，物体=1 背景=0）。
- 四模态由**同一相机、同一 800×800** 生成。

## 3. 相机参数如何映射（tools/camera_utils.py，已单测）
- **外参**：OpenCV `camtoworld`（+X右/+Y下/+Z前）→ Blender `matrix_world`
  （+X右/+Y上/−Z前），即右乘 `diag(1,-1,-1,1)`。
- **内参**：`fx→lens = fx*sensor_width/W`；主点 `cx,cy` → `shift_x/shift_y`
  （以 `(N-1)/2` 为光心参考，本参考数据 `cx=cy=399.5` → shift=0，即严格居中）。
- 参考数据水平 FOV ≈ 39.6°，与 `fx=1111.11` 一致。

## 4. 配置项（.env）
`TO3D_BLENDER_BIN`（blender 路径）、`TO3D_DATASET_DIR`（输出）、
`TO3D_DATASET_ENGINE`（CYCLES/EEVEE）、`TO3D_DATASET_SAMPLES`、`TO3D_DATASET_TIMEOUT`。

## 5. API
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/v1/generation/{id}/dataset` | 对该模型启动 50 视角渲染任务 |
| GET  | `/api/v1/dataset/{ds_id}` | 进度/状态（含日志尾部） |
| GET  | `/api/v1/dataset/{ds_id}/download` | 下载 zip（支持 `?token=`） |

## 6. 说明与校验建议
- 本仓库无 GPU/Blender 环境时无法端到端渲染；相机换算、meta 结构、Blender 缺失
  处理均已单测，**渲染本身需在装 Blender 的机器上验证**。
- 首次跑建议对 1 个模型渲 2~3 个视角，核对：Color 主体居中、Mask 与主体重合、
  Depth 落在 `scene_box.near~far(2~6)`、Normal 颜色随朝向变化。
- Blender 版本：3.x/4.x；EEVEE 更快、CYCLES 更准（尤其 Normal/Depth）。
- 若你的 Normal 需要相机坐标系而非世界坐标系，在合成器里对法线做一次视图矩阵变换。
