# 生成 3D 模型 · 部署指南

主产品（图 + 文联合生成 3D 模型）的部署。**先选一种"出模型"的后端**，再选一种"运行方式"。

---

## 第 0 步：选后端（TO3D_ADAPTER）

| 值 | 出模型方式 | GPU | 费用 | 何时用 |
|----|-----------|-----|------|--------|
| `mock` | 本地几何 Mock（无真实模型） | 否 | 无 | 开发 / 演示 / 跑通流程 |
| `tencent` | 腾讯云混元生3D API | **否** | 按次 | **最快出真实模型、无 GPU** |
| `http` | 自建混元 3D GPU 服务 | 是 | 机器/电 | 私有化 / 大规模自控 |

> 想立刻出真实模型又没有 GPU → 选 **tencent**。

---

## 第 1 步：装依赖

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r backend/requirements.txt
# 若用腾讯云：
pip install -r backend/requirements-tencent.txt
```

---

## 第 2 步：配置后端

复制 `.env.example` 为 `.env`（放仓库根目录），按所选后端填：

**A. mock（默认，零配置）**
```bash
TO3D_ADAPTER=mock
```

**B. tencent（腾讯云 API，推荐无 GPU 快速上线）**
```bash
TO3D_ADAPTER=tencent
TENCENT_SECRET_ID=你的SecretId
TENCENT_SECRET_KEY=你的SecretKey
TENCENT_REGION=ap-guangzhou
TENCENT_RESULT_FORMAT=GLB
# 多图(多视图)需公网图片 URL：配 COS 桶后前端本地多图自动上传取 URL
TENCENT_COS_BUCKET=your-bucket-1250000000
# 用满 8 视角：据文档补齐其余 ViewType
# TENCENT_VIEW_MAP={"top":"top","bottom":"bottom","left45":"left_front","right45":"right_front"}
```
详见 [`接入腾讯云API.md`](接入腾讯云API.md)。

**C. http（自建 GPU 桥接）**
先按 [`../serving/README.md`](../serving/README.md) 在 GPU 机器上起桥接服务，然后：
```bash
TO3D_ADAPTER=http
TO3D_HUNYUAN_ENDPOINT=http://GPU机器IP:9000
```

---

## 第 3 步：选运行方式

### 方式 1：本地 / VSCode（开发）
```bash
make dev                      # 或 ./scripts/dev.sh
```
VSCode：F5 选 **"运行/调试：to3d 后端"**。打开 http://127.0.0.1:8000

### 方式 2：Docker（推荐单机部署）
```bash
# .env 已配好后端；容器内连宿主 GPU 服务用 host.docker.internal
docker compose up --build
```
打开 http://127.0.0.1:8000（`docker-compose.yml` 会读 `.env` 里的 `TO3D_ADAPTER` 等）。

### 方式 3：生产（对外提供服务）
在方式 2 基础上，务必再设这些（见下一节）并加反向代理。

---

## 第 4 步：生产加固（对外必做）

```bash
TO3D_API_KEY=<强随机串>                 # 开启鉴权(REST 用 Bearer/X-API-Key，WS/下载用 ?token=)
TO3D_ALLOWED_ORIGINS=https://your-domain.com
TO3D_DB_URL=sqlite:////data/to3d.db     # 单机持久化，重启不丢结果
TO3D_OUTPUT_DIR=/data/outputs
TO3D_MAX_CONCURRENCY=2                   # 匹配后端并发能力
```
- 反向代理（nginx/traefik）：TLS、限流、`client_max_body_size 64m`、`proxy_read_timeout 900s`、`/metrics` 仅内网。
- 探针：`/api/health`(存活) `/api/ready`(就绪) `/metrics`(Prometheus)。
- 多副本（PG+Redis+队列）见 [`生产部署.md`](生产部署.md) §4。

---

## 第 5 步：验证

```bash
curl http://127.0.0.1:8000/api/ready        # {"status":"ready","adapter":"tencent"}
```
浏览器打开首页 → 上传 ≥2 张图（含正图）+ 文字 → 立即生成 → 看到进度、六维报告、
3D 预览、下载 GLB/OBJ。

命令行冒烟（mock/tencent 皆可）：
```bash
curl -s -XPOST http://127.0.0.1:8000/api/v1/generation \
  -H 'Content-Type: application/json' \
  -d '{"images":[{"view":"front","url":"https://example.com/f.png","required":true},
                 {"view":"left","url":"https://example.com/l.png"}],
       "prompt":"青花瓷花瓶，细长颈，圈足"}'
# 返回 task_id → GET /api/v1/generation/{task_id} 轮询到 done → /mesh 下载
```

## 常见问题
- **/api/ready 返回 503**：`TO3D_ADAPTER=http` 但没设 `TO3D_HUNYUAN_ENDPOINT`。
- **腾讯云多图只用了单图**：没配 `TENCENT_COS_BUCKET`（多视图需公网 URL）。
- **开鉴权后下载/预览 401**：给链接加 `?token=<API_KEY>`，或把前端放反代鉴权后。
- **Docker 里连不上本机 GPU 服务**：用 `http://host.docker.internal:9000`。
- **50 视角数据集**：是独立工具，见 [`../dataset_tool/README.md`](../dataset_tool/README.md)。
